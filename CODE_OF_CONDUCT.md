# Code of conduct

This repo follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

The short version:

- Be kind. Argue about tools, not people.
- No harassment, no slurs, no personal attacks, nobody's private details.
- Makers: add your own tool, say you're affiliated, and don't run down someone else's.
- Don't game the votes. A vote is what one person actually uses.

It covers issues, pull requests, discussions and anything else in this repo.

To report something, use GitHub's "Report content" on the comment or issue, or [send a private report](https://github.com/proxy-intell/marketing-engineering/security/advisories/new). Maintainers can edit or remove content, and block people who keep at it.
